# mashqgoh mascot: direction prompts (round 1)

Process (same as TulporGo): generate each direction in ChatGPT → save the PNGs to
`brand/mascot/directions/NN-<slug>.png` → pick a direction → vectorise (Illustrator
Image Trace) → snap to the brand palette (script + tests) → model sheet → poses →
legal checklist before trademark filing.

Brand palette (decision 2026-11-12, "A · Zumrad"):
`#0B7A5F` emerald (main), `#FFD23F` yellow (accent), `#10231C` ink, `#FFFFFF`,
background `#F2F7F4`. Character body colours may add one neutral cream/brown.

## Shared block (append to every prompt)

> Original character design, not based on any existing mascot, film, studio or brand.
> Flat vector illustration with clean shapes and soft shading, sticker style with a white
> outline, plain light background #F2F7F4, square 1:1, full body, 3/4 front view.
> Colour palette limited to emerald #0B7A5F, warm yellow #FFD23F, dark ink #10231C,
> white, plus one neutral body colour. Big expressive eyes, friendly and smart, suitable
> for a student exam-practice app used by 10–18 year olds in Uzbekistan. No text, no
> letters, no logos.
